# 📊 Student Performance Progression & Risk Analyzer

**Academic Analytics – Advanced Level**

A Python-based analytics system designed to track and evaluate student performance across semesters, identify academic risks, and generate insightful visual reports for early intervention.

---

## 🚀 Features

* 📈 Trend-based performance progression analysis
* 📚 Subject-wise difficulty indexing
* 📊 Consistency scoring using standard deviation
* ⚠️ Dropout risk detection using threshold logic
* 🔗 Correlation analysis between attendance and marks
* 📉 Outlier and distribution analysis using box plots

---

## 🎯 Objectives

* Early identification of at-risk students
* Generate visual academic progress reports
* Support data-driven academic interventions
* Monitor long-term student performance consistency

---

## 📊 Visualizations Included

* Line plots for semester-wise student trends
* Heatmaps for subject-wise difficulty analysis
* Box plots for performance distribution
* Correlation plots between attendance and scores

---

## 🛠️ Tech Stack

* **Programming Language:** Python
* **Libraries Used:**

  * NumPy – Numerical computations
  * Pandas – Data handling & manipulation
  * Matplotlib – Data visualization
